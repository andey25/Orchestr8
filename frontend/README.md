# Orchestr8 Frontend

A small Next.js UI was used to interact with the Orchestr8 backend. Repository input was collected, the ranking endpoint was triggered, and queue items were displayed as they were popped by agents.

The UI was kept intentionally minimal so that behavior was driven by the backend API.

## Local development

A standard Next.js development server was used. Typical package scripts (npm/yarn/pnpm/bun) were supported by the template.

The UI was usually available at `http://localhost:3000` once the dev server was running.
